Set up and family link

The family link opens the app with the password filled in. Share it only with family.

1. Load this event's photos (on the iPad with the disk)

Open the event's folder on the disk, choose Select All, then Open. Each photo gets a large preview kept on this iPad and a small one sent to the family. Loading the same folder again adds nothing twice. For a very large event, load a few hundred at a time.

2. Mark photos already shortlisted

Open this event's Shortlisted folder on the disk and select everything in it. Photos with matching file names count as chosen and are not saved again.

The iPad copies the selected files before the app sees them, which can take minutes for large photos. The faster way is to paste just the file names, one per line.

3. Save the new picks to the disk

Remove this event for everyone

Deletes the event, its small previews and everyone's picks from the family database. Nothing on the disk changes.
